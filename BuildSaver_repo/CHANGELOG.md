# Changelog

## 4.0 - renamed to Build Saver
- **Load equips the build's gear.** Items are moved from the backpack into their slots and the old items go
  back to the backpack. Nothing is copied or deleted. Slots that were empty in the build are emptied.
  The mod needs only 1-2 free backpack places, and it is build-gated (Steam build 26007962).
- In-game panel: **Rename**, with the real keyboard (see KEYBOARD.md, can be switched off) and an
  on-screen keyboard.
- Panel layout: longer build list, compact details that fill the panel.
- Augments / capstones saved for action skills that are not equipped no longer count as "failed".
- Co-op guests: gear is not touched (host only).

## 2.4 - 3.x (Skill Saver)
- In-game panel on the skill page (save, load, overwrite, delete, undo, reset tree; skills / gear tabs).

## 1.x (Skill Saver)
- Save and load complete skill setups. Item names, firmware and elements for saved gear.
